# marketlab

מחקר שוק → CNN → מסחר בכסף וירטואלי, על מדד NASDAQ-100.

המערכת אוספת יותר מ-20 שנות נתוני שוק, מאקרו, תחזיות, חדשות ואירועי עולם, מצמידה אותם
למדד יום-יום, מאמנת CNN שמנסה לחזות את כיוון המדד, ובודקת את התחזיות בחשבון מסחר וירטואלי.

## הפעלה

```bash
pip install -r requirements.txt
python -m marketlab run-all     # הכול מהתחלה: כ-10 דקות הורדה + כ-20 דקות אימון על 4 ליבות
python -m marketlab daily       # שגרה יומית: עדכון נתונים, צעד בחשבון הוירטואלי, דוח
python -m pytest -q tests
```

| פקודה | מה היא עושה | פלט |
|---|---|---|
| `fetch` | מורידה ומעדכנת את כל מקורות הנתונים | `data/raw` |
| `build` | כותבת את טבלת הפיצ'רים לדיסק לעיון | `data/processed` |
| `research` | מחקר אירועים ו-IC לכל פיצ'ר | `runs/research` |
| `train` | אימון walk-forward לכל גרסאות המודל | `runs/latest`, `models/production.pt` |
| `backtest` | ציון החיזוי מחוץ למדגם וסימולציה בכסף וירטואלי | `runs/latest` |
| `paper init / step / status` | חשבון המסחר הוירטואלי קדימה בזמן | `state/paper_account.json` |
| `report` | דוח HTML | `reports/latest.html` |
| `status` | מה יש על הדיסק וכמה הוא עדכני | |

כל ההגדרות נמצאות ב-`config/default.yaml`.

| סוג | מקור | הערות |

| סנטימנט חדשות | SF Fed Daily News Sentiment | מתעדכן שבועית |

## העיקרון שמחזיק את הכול: בלי מידע מהעתיד

- שורה של יום t מכילה רק מה שאפשר לדעת בזמן כדי לשלוח הוראה שתבוצע בסגירה של יום t+1.
- לכל סדרה הוגדר עיכוב הפרסום האמיתי שלה (`config/default.yaml`).
- כל שנת מבחן נחזית על ידי מודל שאומן רק על נתונים שהתוויות שלהם נסגרו לפניה, כולל נרמול.
- שנות המבחן עד 2018 שימשו לבחירת התכנון; 2019 ואילך נבדקו רק אחרי שהתכנון נקבע.
- הבדיקות ב-`tests/test_point_in_time.py` בונות את הטבלה מחדש מנתונים חתוכים ומוודאות שכל שורה זהה.

## המודל והאסטרטגיה

- `marketlab/model/cnn.py`: חמישה ענפים (שוק, ריביות, מאקרו ותחזיות, חדשות ואירועים, לוח שנה), בכל אחד
  קונבולוציות סיבתיות על 60 ימי המסחר האחרונים. הפלט: הסתברות לעלייה ב-1, 5 ו-20 ימים.
- `marketlab/trading/strategy.py`: ברירת המחדל היא להיות מושקע כמו קנה-והחזק. החשיפה יורדת כשהמודל
  פסימי יחסית לתחזיות של עצמו בשנה האחרונה. אין מינוף ואין שורט.
- `marketlab/features/rules.py`: תשע שיטות מסחר קלאסיות (מגמה, חציית ממוצעים, מומנטום, פריצה, MACD,
  RSI, בולינגר, יעד תנודתיות, סוף-חודש). הן נסחרות באותו חשבון וירטואלי כמתחרות ל-CNN, וגרסת המודל
  `cnn_rules` מקבלת את האותות שלהן כקלט נוסף.
- `marketlab/trading/broker.py`: עלות לכל עסקה, ריבית על מזומן, ואותו קוד בדיוק לסימולציה ההיסטורית
  ולחשבון הוירטואלי קדימה.

## מה לא נשמר ב-git

`data/`, `runs/`, `models/` ו-`reports/` נוצרים מחדש מהפקודות למעלה. `state/` (החשבון הוירטואלי) כן נשמר.
